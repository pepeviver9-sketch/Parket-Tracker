## 📌 Descripción

Cisco Packet Tracer es un software desarrollado por Cisco que permite
diseñar, configurar y simular redes informáticas de manera virtual.
## 🌐 Cisco Packet Tracer

![Cisco Packet Tracer](https://github.com/pepeviver9-sketch/Parket-Tracker/blob/23cac311557d3b8999cbe2d38eafedbaae559c43/images.jpeg)
Esta herramienta facilita el aprendizaje de redes y permite practicar
con routers, switches, computadores y servidores sin necesitar todos
los dispositivos físicos.

## 🎯 Objetivo

Comprender el funcionamiento de las redes informáticas y analizar
su importancia en la comunicación digital y en el funcionamiento
de las plataformas de redes sociales.

## ⚙️ Características principales

- Diseño de topologías de red.
- Simulación de routers y switches.
- Configuración de direcciones IP.
- Pruebas de conectividad mediante ping.
- Simulación de protocolos de comunicación.
- Configuración de servicios de red.
- Análisis del envío de paquetes.
- Aprendizaje de conceptos de seguridad informática.

## 📱 Relación con las redes sociales

Las redes sociales, como Instagram, Facebook, TikTok y WhatsApp,
utilizan infraestructuras de red para permitir la comunicación
entre usuarios y servidores.

Packet Tracer permite estudiar algunos de los fundamentos de
comunicación que hacen posibles estos servicios.

### Ejemplo de funcionamiento

1. Un usuario utiliza un computador o dispositivo móvil.
2. El dispositivo se conecta a una red.
3. El router permite la comunicación con otras redes.
4. Los datos viajan mediante protocolos de comunicación.
5. Un servidor procesa las solicitudes del servicio digital.
6. La respuesta vuelve al dispositivo del usuario.

**Nota:** Packet Tracer permite simular componentes y servicios de
red, pero no ejecuta directamente las aplicaciones reales de redes
sociales.

## 🖥️ Dispositivos utilizados

| Dispositivo | Función |
|---|---|
| Router | Conecta diferentes redes. |
| Switch | Conecta dispositivos en una red local. |
| PC | Representa el equipo del usuario. |
| Server | Proporciona servicios de red. |
| Cable Ethernet | Conecta dispositivos compatibles. |

## 🔬 Práctica propuesta

### Construcción de una red para una plataforma social ficticia

**Materiales virtuales:**
- 3 computadores.
- 1 switch.
- 1 router.
- 1 servidor.

### Pasos

1. Crear una topología de red.
2. Conectar los computadores al switch.
3. Conectar el switch al router.
4. Incorporar el servidor a la topología.
5. Asignar direcciones IP.
6. Configurar las interfaces necesarias.
7. Ejecutar pruebas de conectividad.
8. Analizar el recorrido de los paquetes.

## ⚠️ Limitaciones

- No reemplaza completamente los equipos físicos.
- No ejecuta directamente las redes sociales comerciales.
- Algunas funciones dependen de la versión instalada.
- No reproduce todos los comportamientos de Internet.

## 🔐 Importancia de la seguridad

La seguridad de las redes es fundamental para proteger la información
de los usuarios de plataformas sociales.

Algunos conceptos importantes son:

- Control de acceso.
- Contraseñas seguras.
- Segmentación de redes.
- Protección de servidores.
- Uso de protocolos seguros.
- Actualización de los dispositivos.
